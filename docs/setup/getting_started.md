# Getting Started

Setting up your own instance of ChadMusic is not difficult to do, but it also requires at least some knowledge on using a terminal. By following each page in order, you'll be able to have your bot up and running in no time. This guide will assume that you will be hosting the bot on a server running Linux, but the bot will run on any operating system that can run Node.js.

If you want to try out ChadMusic before you begin the setup process, you can either invite my own bot to your server by clicking on the button below, or you can try it out in the [support server](https://discord.com/invite/qQuJ9YQ).

[:material-robot: Invite the bot](https://discord.com/api/oauth2/authorize?client_id=375450533114413056&permissions=41099548028374&scope=bot%20applications.commands){ .md-button .md-button--primary }

There are some things to take into consideration if you're adding my bot to your server:

* The bot is limited to 50 servers. It's under a first come, first serve basis.
* The bot may leave at anytime for any reason.
* It preiodically runs an in development build of ChadMusic.

If you're ready to start setting up ChadMusic, please continue to the next page.
